# Silico Landing Copy Source (V1)

## Hero
- Headline: `Stop guessing, start predicting`
- Subhead: `Silico removes trial-and-error from chromatography method development with molecule-native AI workflows that simulate separation behavior before lab runs`
- Primary CTA: `Book pilot call`

## Problem
- Current HPLC workflows are bottlenecked by manual iteration.
- Chemists test many parameter combinations before finding adequate separation.
- This increases time, solvent usage, and equipment/labor cost.

## Solution
- Simulate first and run fewer physical experiments.
- Use in-silico screening to identify robust settings before lab execution.
- Positioning pillars: simulated separation, lower waste, improved precision.

## Technology
- Molecule-native architecture with graph-based representation.
- Workflow: aggregate predictions, scan parameter grid, deliver optimum candidates.
- Avoid LLM framing for molecular inference narrative.

## Product Workflow
1. Input mixture.
2. Explore optimization landscape.
3. Inspect chromatogram and separation metrics.
